4. ТЕХНИЧЕСКОЕ ЗАДАНИЕ
 
4.1. Общие сведения
Наименование: Информационная система учета техники техникума.
Назначение: Учет оборудования, кабинетов, ответственных лиц и обслуживания.
Пользователи: Администратор (полный доступ), Оператор (добавление техники и работа со справочниками).
Технологии: Python + Flask, база данных SQLite.
 
4.2. Функциональные требования
1. Просмотр общего списка оборудования.
2. Добавление карточки оборудования с проверкой уникальности инвентарного номера.
3. Поиск по названию или инвентарному номеру.
4. Изменение места размещения, статуса и ответственного лица.
5. Ведение справочников категорий, помещений и ответственных лиц.
6. Разграничение прав доступа (роли «Администратор» и «Оператор»).
7. Регистрация новых пользователей.
8. Экспорт базы данных в формат CSV для работы в Excel.
9. Создание резервной копии базы данных (только для Администратора).
