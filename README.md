 РУКОВОДСТВО ОПЕРАТОРА
 
1. Назначение и вход в систему
Система хранит сведения о компьютерной и офисной технике, кабинетах, ответственных лицах и обслуживании. Работа выполняется в браузере.
Для входа откройте адрес системы, введите логин и пароль (например, admin / 123456). Если у вас нет аккаунта, нажмите кнопку «Зарегистрироваться».
 
2. Главная страница и реестр
После входа открывается «Панель управления». В верхней части отображаются карточки со статистикой (Всего техники, В эксплуатации, Общая стоимость).
В разделе «Реестр» доступна таблица с оборудованием. Для поиска введите название или инвентарный номер в строку поиска. Для выгрузки в Excel нажмите «Экспорт в CSV».
 
3. Добавление техники
Перейдите в раздел «Постановка на учет». Заполните обязательные поля: Инвентарный номер и Наименование. Выберите Категорию, Помещение и Ответственного из выпадающих списков. Укажите Стоимость и нажмите «Сохранить». Если номер уже существует — система выдаст ошибку.
 
4. Справочники
Раздел «Справочники» позволяет добавлять новые категории техники, кабинеты и ФИО сотрудников. Роль «Оператор» может только добавлять записи, а удалять их может только «Администратор».
 
5. Резервное копирование
Зайдите в раздел «Резервные копии» (доступен только Администратору). Нажмите «Создать резервную копию». Файл базы данных сохранится в папке проекта с расширением .db.
